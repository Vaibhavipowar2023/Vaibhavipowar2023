## 🧬 About Me

I'm an **AI Engineer** passionate about building practical Generative AI applications, specializing in Voice AI, Retrieval-Augmented Generation (RAG), and AI Agents.

At **SMILO**, I work on real-time conversational AI systems that enable multilingual interactions, automate workflows, and deliver voice-based AI experiences.

I enjoy turning AI concepts into practical engineering solutions.

- 🎙️ Building real-time Voice AI pipelines using STT, LLMs, and TTS.
- 🤖 Designing AI agent workflows with routing and tool calling.
- 🔍 Developing RAG systems with hybrid retrieval and reranking.
- 📊 Evaluating RAG pipelines using RAGAS metrics.
- ⚙️ Building AI-powered backend services using Python and FastAPI.
- 🌱 Exploring emerging AI technologies and building hands-on projects.
